## WorkspaceIcons

`AppRules.mjs` adapts the application icon rules from
https://github.com/SaifOmar/WorkspaceIcons at commit
`e331ad3ecfd30d8b8bcb4f30066db297cbb60099`.

Changes: app-ID-only matching, token boundaries, a narrower GitHub rule,
additional application mappings, and webapp rules before generic browser rules.
